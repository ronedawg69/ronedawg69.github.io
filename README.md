# Cycle Signals

Cycle Signals is a small, static website project for learning how to combine weather with fictional cycling and sleep signals. The project is being built lesson by lesson, with a focus on understanding the code, keeping examples synthetic, and treating privacy carefully.

**Live site:** [ronedawg69.github.io](https://ronedawg69.github.io/)
